STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Controllers/   -> HTTP endpoints only (thin controller)
DTOs/          -> Request/Response DTOs
  Auth/        -> LoginDto, RegisterEmployeeDto, AuthResponseDto, CurrentUserDto
  Common/      -> ApiResponse<T> (wrapper chung cho mọi response)
Models/        -> Entity models
  Enums/       -> Enum types
Data/          -> AppDbContext, EF Configurations
  Configuration/ -> IEntityTypeConfiguration<T>
Repositories/  -> Database access (dùng khi query phức tạp)
Services/      -> Business logic (IFooService + FooService)
Mappings/      -> Entity <-> DTO (extension methods)
Validators/    -> FluentValidation hoặc DataAnnotations
Exceptions/    -> AppException, NotFoundException, ConflictException...
Middleware/    -> ExceptionHandlingMiddleware (global error handler)

REQUEST FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HTTP Request
    -> ExceptionHandlingMiddleware   (bao ngoài toàn bộ pipeline)
    -> Controller                    (validate input, gọi service)
    -> Validator                     (DataAnnotations / FluentValidation)
    -> IFooService                   (business logic)
        -> AppDbContext / Repository (database query)
        -> Mappings                  (entity -> DTO)
    -> ApiResponse<T>.Ok(data)       (wrap response)
    -> HTTP Response

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RESPONSE FORMAT (BẮT BUỘC thống nhất)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Thành công:
{
  "success": true,
  "message": "...",
  "data": { ... }      // hoặc null nếu không có data
}

Lỗi:
{
  "success": false,
  "message": "...",
  "errors": [ ... ]    // optional, dùng cho validation errors
}

Dùng ApiResponse<T> wrapper:
  return Ok(ApiResponse<FooResponse>.Ok(data, "Thành công"));
  return StatusCode(201, ApiResponse<FooResponse>.Ok(data, "Tạo thành công"));
  return Ok(ApiResponse.OkNoData("Đăng xuất thành công."));

EXCEPTION HANDLING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Service throw AppException (không return HTTP result)
- ExceptionHandlingMiddleware bắt và map sang HTTP status + ApiResponse

  throw new NotFoundException("Sản phẩm không tồn tại.");        -> 404
  throw new ConflictException("SKU đã tồn tại.");                 -> 409
  throw new ForbiddenException("Không có quyền.");                -> 403
  throw new BadRequestException("Dữ liệu không hợp lệ.");        -> 400
  // Unexpected exception                                          -> 500

- Controller KHÔNG try/catch thủ công

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.  Controller chỉ: nhận request, gọi service, trả ApiResponse. Không có logic.
2.  Service xử lý toàn bộ business logic. Throw AppException khi lỗi.
3.  Repository xử lý database queries phức tạp. Query đơn giản dùng thẳng DbContext trong Service.
4.  DTO dùng cho API input/output. KHÔNG expose Entity trực tiếp.
5.  Validators validate Request DTOs (DataAnnotations hoặc FluentValidation).
6.  Mapping nằm trong Mappings/ (extension methods). KHÔNG map inline.
7.  Dùng async/await cho mọi database operation.
8.  HTTP Status codes:
    200 OK           -> GET, PUT thành công
    201 Created      -> POST tạo resource thành công
    204 NoContent    -> DELETE thành công
    400 BadRequest   -> input không hợp lệ
    401 Unauthorized -> chưa đăng nhập
    403 Forbidden    -> không có quyền
    404 NotFound     -> resource không tồn tại
    409 Conflict     -> trùng dữ liệu
    500 Internal     -> lỗi hệ thống
9.  Route: plural, lowercase, versioned: /api/v1/products, /api/v1/employees
10. C# dùng PascalCase. Database dùng snake_case (auto qua EFCore.NamingConventions).
11. JSON response: camelCase. Không escape Unicode (\uXXXX).
12. Secrets (connection string, JWT key) KHÔNG commit lên Git. Dùng appsettings.json local.
